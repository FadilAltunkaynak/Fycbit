# Environment Reference

## Backend

Use `apps/backend/.env.example`. Required for basic startup:

- `APP_KEY`: generated by `php artisan key:generate`
- `APP_URL`: backend URL
- `DB_*`: dedicated MySQL connection
- `REDIS_*`: local Redis connection
- `QUEUE_CONNECTION`: use `redis` for workers or `sync` for minimal debugging
- `BROADCAST_DRIVER`: keep `null` until websockets are configured

Payment, exchange, mail, social login, and blockchain integrations are optional
and must stay disabled until test credentials are available.

## Web

Use `apps/web/.env.example` as `.env.local`.

- `NEXT_PUBLIC_BASE_URL`: Laravel URL without `/api`
- `NEXT_PUBLIC_HOSTED_CLIENT_URL`: browser URL with trailing slash
- `NEXT_PUBLIC_HOST_SOCKET`: websocket hostname
- `NEXT_PUBLIC_WSS_PORT`: websocket port
- `NEXT_PUBLIC_DEMO_MODE=1`: recommended for review

Every `NEXT_PUBLIC_*` value is visible to every browser user. The current code
references `NEXT_PUBLIC_SECRET_KEY` and `NEXT_PUBLIC_EVM_APP_SECRET`; they must
contain only non-sensitive compatibility placeholders. Authentication based on
these fields must be redesigned before production use.

## Wallet Service

Use `apps/wallet-service/.env.example`.

- `NODE_ENV`, `PORT`, and `DATABASE_URL`
- JWT lifetime values and a random local `JWT_SECRET`
- Optional SMTP settings
- Block processor feature flags

Keep all block processors disabled until chain-specific testnet configuration
and replay/idempotency behavior have been reviewed.
