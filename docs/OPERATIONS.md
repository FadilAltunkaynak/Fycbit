# Operations

Before any production evaluation:

1. Complete legal, dependency, and source-ownership review.
2. Run static analysis, unit/integration tests, and migration review.
3. Perform independent application and custody security audits.
4. Use testnet/devnet and synthetic users.
5. Test database and configuration restore procedures.
6. Establish monitoring, key rotation, incident response, and rollback.

This repository does not provide a custody guarantee.
