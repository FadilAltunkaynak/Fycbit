# Public Release Checklist

- [ ] Ownership and redistribution rights confirmed
- [ ] License decision approved
- [ ] `.env`, credentials, keys, dumps, logs, and user data absent
- [ ] Full Git history scanned with a recognized secret scanner
- [ ] Dependencies and bundled assets reviewed
- [ ] SBOM generated
- [ ] Tests, lint, builds, and migration review passed
- [ ] Testnet/devnet behavior documented
- [ ] Security contact verified
- [ ] Release notes identify included and excluded components
