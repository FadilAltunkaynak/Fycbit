# License Decision Required

Before an open-source release, confirm ownership of every application module
and choose a license deliberately:

- AGPL-3.0 for network software whose modified deployments should publish
  corresponding source.
- Apache-2.0 for a permissive license with an explicit patent grant.
- A reviewed source-available or commercial license for restricted use.

Do not apply one project-wide open-source license to purchased, proprietary, or
third-party modules without written redistribution rights.
