Introduction

Details

For Tradexpro Exchange we made a feature named ICO(Initial coin offering) Launchpad. It will run with the help of Tradexpro Exchange (Main Project). An initial coin offering (ICO) is the cryptocurrency industry’s equivalent of an initial public offering (IPO). A company seeking to raise money to create a new coin, app, or service can launch an ICO as a way to raise funds. Here both user and admin can create their own token, and can sell their token to another user. User can buy token by using their existing coin, bank, credit card, paypal etc. We support only erc20 and bep20 token. when user buy token, we send him token via blockchain transaction.

Installation Process

Addon Installation

Addon Name: Ico Launchpad

  • It's a super easy installation process

    • Warning ! You must have the latest updated admin file (tradexpro laravel), then start the next process

    Remember : It's just an addon. It does not run alone. It will run with the help of "Tradexpro Exchange" project.

    So you must have the "Tradexpro Exchange" Project first

    Here we integrate the new addon "Ico Launchpad" to Tradexpro Exchange project that was already running

  • Fresh tradexpro project that is running already

  • Look here is no "ICO" feature

  • This is the current folder structure

    • To integrate this addon, we must follow the bellow procedure

    # Step 1 :


    Go to project directory and open the terminal or Open the terminal then go the project directory

  • Run this command in project directory

    "composer install --ignore-platform-reqs"

    "composer dumpa --ignore-platform-reqs"

    • # Step 2 :

    First create "Modules" folder in project root directroy (if not exist) and go in.


    # Step 3 :

    Put the zip file that we provide in the modules folder.

    Here extract zip file that you already put in modules folder.

    Now delete the zip file from modules folder.

    # Step 4 :

    Then go to the project path (like ..tradexpro-exchange/) , and run some commands below.

    "php artisan module:enable icoLaunchpad"


  • Then you get this message after enable the module successfully.

    • # Step 5 :

  • Then Need to run the module migration command

    • "php artisan module:migrate icoLaunchpad"


  • Then you get this after successfully run the command

    • Installation is done

    # Step 6

    Now you can enable/disable this module from Admin panel

    Screenshot of before enable

    Now, you need to go "Features" from "Settings" menu. Here, you cana see "Module Settings" sub-menu. From here, you have to "enable" ICO module to use ICO module in your project.

    You can see "ICO" menu in left side bar after successfully enabled the the ICO.
