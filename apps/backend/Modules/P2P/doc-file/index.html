Details

For Tradexpro Exchange we made a feature named P2P(Peer To Peer). It will run with the help of Tradexpro Exchange (Main Project). P2P trading, or peer-to-peer trading, refers to a type of trading where two individuals directly exchange assets without the involvement of a central authority or intermediary. In the context of financial markets, P2P trading usually involves the exchange of cryptocurrencies, such as Bitcoin or Ethereum. P2P trading platforms allow buyers and sellers to connect with each other and negotiate the terms of their trade, such as the quantity of assets being exchanged and the price at which they will be traded. The platform typically provides a secure escrow service that holds the assets until the trade is completed and verified by both parties. P2P trading has become popular due to its decentralized nature, which allows individuals to trade directly with each other without relying on traditional financial institutions. This can lead to lower transaction fees and faster transaction times compared to traditional financial systems.

Installation Process

Local Installation (Admin Part)

Setup for local pc

  • It's a super easy installation process
  • First Run The Command "composer dumpa --ignore-platform-reqs"
  • Warning ! You must have the latest updated admin file, then start the next process

    • First create "Modules" folder in project root directroy (if not exist) and go in.

    Put the zip file that we provide in the modules folder.

    Here extract zip file that you already put in modules folder.

    Now delete the zip file from modules folder.

    Then go to the project path (like ..tradex_admin/) , and run some commands below.

  • php artisan module:enable P2P

  • Then you get this message after enable the module successfully.
  • Module [P2P] enabled successful.

  • Then run migrate to adjust database table "php artisan module:migrate --seed P2P"

  • Installation is done

    • Now you can enable/disable this module from Admin panel

    Screenshot of before enable

    Now, you need to go "Addons Setting" from "Addons" menu. Here, you can see "Addons Setting" sub-menu. From here, you have to "enable" P2P module to use P2P module in your project.

    Then you need to go "Addons List" from "Addons" menu. Here you can see "Addons List" sub-menu. From here , you can manage your addon

    Now click on "Manage" and it will redirect you to your P2P addon dashboard
