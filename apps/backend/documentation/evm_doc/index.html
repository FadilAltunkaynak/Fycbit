Introduction

Details

With this EVM Network Support Addon, your Tradexpro Exchange will support all EVM based Network. Ethereum Blockchain with Native and ERC20 tokens will be supported. BNB Smart Chain (BSC) Blockchain with Native and BEP20 tokens will be supported. TRON Blockchain with native and TRC20 tokens will be supported. Polygon (MATIC) Blockchain with native and Polygon tokens will be supported. So, you won't have to rely on Coin Payment or BitGo for EVM based native coins and tokens. No third party API needed for EVM based coins and tokens.

Getting Started

The application has a few system requirements, so you will need to make sure your server meets the following requirements:

Admin side requirement :

  1. It will run with Tradexpro Exchange Main Project, So everything is same as main project

User side requirement :

  1. Nodejs 16.16.0
  2. Yarn 1.22.19 or above
  3. Nginx

Installation Process

  • We provide free installation service. if you get problem contact us
  • First make a Backup file and Database of current version
  • Replace the Tradexpro Exchange Backend project with the Backend project of EVM Addon
  • Then Replace the Tradexpro Exchange Frontend project with the Frontend project of EVM Addon
  • Then navigate to the Backend project directory
  • And run the command "composer install --ignore-platform-reqs"
  • Then run the command "composer dumpa"

    • Then run the command "php artisan migrate --seed" to migrate new database table.

    Then run the command "php artisan command:existingwalletaddress" to encrypt existing user's wallet private key.

    Then run the command "php artisan command:updatesystemwallet" to create System Wallets.



  • Create a new sub domain for Evm addon.
    Let's assume that your domain name is example.com
    Then you need a sub domain like evm.example.com
    Make sure that this sub-domain is poined to your server ip.

    Navigate to the directory to /var/www/

    Command:

    cd /var/www/

    mkdir evm (evm is the folder name)

    Extract the EvmWallet.zip file and this will create a folder named EvmWallet.
    Move the contents of this folder to the directory /var/www/evm/

  • Now go to the evm folder

    Command:

    cd /var/www/evm/

    cp .env.example .env

    nano .env

    Inside this env file, as displayed on the screen below,
    put your MySQL Username, Password and Database names at the marker 1,2 and 3 respectively.
    On the marker 4, put an API secret key.

    Then run the following commands on the same directory

    yarn install

    yarn build

    Then you need to keep the command "yarn start" runnung on the same directory.
    You can use pm2 to keep that command running.
    On the same /var/www/evm/ directory, run the following commands.

    sudo npm install pm2 -g

    pm2 start yarn --interpreter bash --name EvmWallet -- start

  • Then go to this path

    Command:

    cd /etc/nginx/sites-available/

    nano evmwallet

    in the file write down these code 

    
                                    server {
                                        root /var/www/evm/;
                                        index index.php index.html index.htm index.nginx-debian.html;
                                        server_name evm.example.com;
                                
                                        location / {
                                          proxy_pass    http://127.0.0.1:3040;
                                        }
                                
                                        }

    Then run this command

    sudo ln -s /etc/nginx/sites-available/evmwallet /etc/nginx/sites-enabled/

    service nginx reload

    service nginx reload

  • Then Add the following 2 keys in Tradexpro Backend ".env" file

    EVM_APP_HOST=url/to/your/EvmWallet (example: https://evm.example.com/v1 )

    EVM_APP_SECRET=yout_secret_key_from_EvmWallet_evm

  • And Add the following 2 keys in Tradexpro Fronted ".env" file

    NEXT_PUBLIC_EVM_APP_HOST="url/to/your/EvmWallet" (example: https://evm.example.com/v1 )

    NEXT_PUBLIC_EVM_APP_SECRET="yout_secret_key_from_EvmWallet_evm"

  • Now navigate to the directory where your Frontend project is located. And run the following commands

    yarn install

    yarn installs

    Then if your Frontend project was running on pm2,
    run "pm2 restart all" on this same directory to restart the Frontend.
